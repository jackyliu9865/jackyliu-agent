# Deck profile — Talkbook

**Not written yet, and blocked.** A separate layout is to be supplied. Do not
build a talkbook on the current master and call it one.

Read [[START-HERE]] first.

## Why this one is blocked rather than merely unwritten

The other two profiles ride the bundled master, which carries a closer for each
of them. This master has three back covers: `Back Cover_Report`,
`Back Cover_Proposal` and `Back Cover_Publications`. **None is a talkbook.**

The master is also built for dense, read-alone documents: 9pt body, 12.60 cm of
content height, a mandatory source strip. A talkbook is read for about 20 seconds
a slide while somebody talks over it, which is the opposite requirement.

## What is needed before this file is written

- **The layout.** A `.pptx` or `.potx` for the talkbook master. Drop it in this
  folder.
- **The closer.** Borrow `Back Cover_Publications`, or take whatever the new
  layout ships.
- **Type scale.** The bundled master fixes 44/9/8/6 and the skill forbids
  overriding it. A talkbook needs larger body text, so this almost certainly
  comes from the new master rather than from an override.
- **Density cap.** The one rule that stops a talkbook becoming a report.

## Until then

A live-presented deck built on the current master is a report being presented.
Say so rather than labelling it a talkbook.
