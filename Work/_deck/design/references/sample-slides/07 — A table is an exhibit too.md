## Table 1

| Financials | 12.4 | 13.1 | +0.7 |
| Industrials | 8.9 | 8.2 | (0.7) |
| Technology | 17.2 | 19.6 | +2.4 |
| Materials | 6.1 | 5.8 | (0.3) |
| Utilities | 4.4 | 4.9 | +0.5 |

## The read

- Only technology improved by more than one percentage point
- Industrials and materials both went backwards
- Row height comes from the row count, not from stretching to fill a box
- Numeric columns right-align and keep a gap from the next column
